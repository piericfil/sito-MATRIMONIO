Esegui questa procedura di sicurezza per salvare il lavoro su GitHub:

1. Controlla lo stato delle modifiche con `git status`.
2. Aggiungi tutti i file modificati o nuovi con `git add .`.
3. Chiedi all'utente un messaggio breve per il commit (se l'utente non lo specifica, proponine uno tu basato sulle modifiche).
4. Esegui il commit con `git commit -m "MESSAGGIO"`.
5. Invia le modifiche al cloud con `git push`.
6. Conferma all'utente che il checkpoint è stato salvato con successo.

Se il repository non è ancora collegato, chiedi l'URL all'utente e collegalo con `git remote add origin URL`.
